# Правило проекта

**Источник истины — оригинал кода** (`src/Assembly-CSharp`, декомпилят игры).

- Всегда ориентируемся на него; ничего не выдумываем.
- Каждая строка `runtime/` должна быть подкреплена конкретным методом оригинала
  (ссылка в комментарии).
- Расхождение не затыкается эвристикой — оно либо чинится по коду, либо
  документируется в `runtime/README.md` как открытый вопрос с числами.
- Данные уровней (`levels/*.json`) — тоже источник: константы берём оттуда,
  не хардкодим.
